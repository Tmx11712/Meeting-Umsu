Gemini AI siap
Koneksi OpenAI API Belum terhubung
API key disimpan hanya di sesi browser ini (tidak dikirim ke server manapun selain langsung ke OpenAI). Dapatkan dari platform.openai.com.
Belum ada file dipilih
Unggah berkas rekaman rapat (mp3/wav/m4a, hasil OBS/Zoom/Teams). Berkas di atas 24MB akan otomatis dipecah menjadi beberapa bagian.
Belum mulai merekam
Browser akan menampilkan dialog "Choose what to share" — pilih tab/jendela rapat (Zoom/Teams/dll) dan pastikan centang "Share system audio". Fitur ini paling konsisten di Windows + Chrome/Edge; biarkan tab ini tetap terbuka selama rapat berlangsung.
